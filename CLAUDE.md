# armycoding.com

Public landing site for **Army Coding** — a disciplined, AI-native software-development methodology (the opposite of "vibe coding"). Static site, deployed via GitHub Pages (`CNAME` → armycoding.com).

## What lives here

Only the public website: `index.html`, `styles.css`, assets, and the design mockups (`cartoon.html`, `tactical.html`). This repo is **public** — keep it that way.

## What does NOT live here

The methodology — doctrine, decision records, strategy, prior-art, tooling — lives in the **private** `grokitlabs/armycoding` repo. The site surfaces polished projections of that source; it never contains the raw artifacts. If you're about to add a strategy/planning/methodology doc here, it belongs in the private repo instead.

## Voice

Army Coding voice: irreverent, confident, plain, funny — with real rigor underneath. Keep the site simple; digestibility is the product.
